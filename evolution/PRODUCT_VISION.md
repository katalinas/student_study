# 产品愿景

## 一句话定位
面向6-15岁学生的跨平台德智通识教育软件，以科技探索和智力训练为核心，培养面向未来的综合素养。

## 目标用户

| 用户群 | 年龄 | 特征 |
|--------|------|------|
| 低龄段 | 6-8岁（小学1-3年级） | 注意力短、需要强视觉引导、游戏化驱动 |
| 中龄段 | 9-11岁（小学4-6年级） | 有一定自主学习能力、喜欢挑战和竞争 |
| 高龄段 | 12-15岁（初中7-9年级） | 需要知识深度、关注实用性和成就感 |
| 家长 | - | 需要学习报告、时长控制、内容安全 |

## 核心价值

1. **科技素养** - 编程、AI、实验模拟，培养未来技能
2. **思维训练** - 逻辑推理、策略博弈，锻炼思考能力
3. **知识广度** - 智育基础 + 通识百科，构建知识体系
4. **品德基础** - 轻量融入传统文化与品德教育

## 模块权重

| 模块 | 权重 | 定位 |
|------|------|------|
| 智育学堂 | ★★★ 30% | 核心学科基础 |
| 科技探索 | ★★☆ 25% | 重点特色模块 |
| 逻辑训练 | ★★☆ 20% | 思维能力培养 |
| 通识百科 | ★☆☆ 15% | 知识面拓展 |
| 德育融入 | ★☆☆ 10% | 轻量品德教育 |

## 平台策略

- **V1.0**: Windows + Android（Flutter单代码库）
- **V2.0**: 追加 iOS + Web
- **V3.0**: 追加平板优化 + 教师端

## 商业模式（远期）

- 基础内容免费
- 高级内容/模块订阅制
- 学校/机构批量授权

## 长期目标

1. **Year 1**: 核心功能上线，5个模块基础内容完整
2. **Year 2**: 内容库扩充至5000+条目，增加社区功能
3. **Year 3**: 接入AI辅导、自适应学习路径、教师后台
