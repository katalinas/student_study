# 版本路线图

## V1.0 — 基础版（MVP）

**目标**: 核心功能可用，5模块基础内容上线

### V1.0-alpha（Phase 1: 第1-3周）— 基础框架

| 任务 | 状态 | 说明 |
|------|------|------|
| Flutter 项目初始化 | `done` | 双平台配置、Riverpod、go_router |
| UI 设计系统 | `done` | 儿童友好主题、色彩、字体、基础组件 |
| SQLite 数据层 | `todo` | drift 已安装但未启用，当前使用 SharedPreferences |
| JSON 内容加载引擎 | `done` | 解析器、缓存、年龄段过滤 |
| 答题引擎 | `done` | 选择/填空/判断/连线/拖拽题型支持 |
| 用户系统 | `done` | 本地多用户、年级选择、头像 |

## 版本状态定义

| 状态 | 含义 |
|------|------|
| `todo` | 计划中，未开始 |
| `in_progress` | 开发中 |
| `done` | 已完成 |
| `deferred` | 推迟到后续版本 |
| `cancelled` | 取消 |
